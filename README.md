# ASSSMER · 安卓本地播放器

离线本地音频播放器，Android 8.0 及以上。应用不申请网络权限，不需要登录。

## 使用

1. 从本仓库 Releases 下载并安装 `ASSSMER-0.2.2.apk`；本地打包版本在 `dist` 文件夹。此版本为测试安装包，尚未上架应用商店。
2. 打开「音频库 → 导入文件夹」，在安卓系统选择器中选择作品目录并授权。
3. 应用递归扫描子文件夹，以音频实际所在目录分组。点击分组，再选择曲目播放。
4. 同目录同名的 TXT、VTT、SRT、LRC、ASS、SSA 自动关联，也识别 `名称.wav.vtt`、`名称.mp3.lrc` 等带完整音频文件名的字幕。播放页「关联 / 格式 ▾」可切换或手动选择字幕。
5. 播放页支持字幕点击跳转、同步偏移、字体大小、倍速、10 秒快进快退、上一段 / 下一段、单段 / 分组循环及睡眠定时。
6. 播放可以在后台继续；通知栏和锁屏使用系统媒体控制。收藏和播放进度会保留。
7. 新增或移动文件后，在「设置 → 重新扫描」更新。移除目录只移除音频库记录，不删除源文件。

### 批量导出

进入音频文件夹，点「批量导出 TXT」，选择 VTT 或 LRC。首次需要通过系统选择器允许音频文件夹或上级目录的写入权限，之后自动复用授权。
批量处理该分组中与音频同名的 TXT（包括 `名称.wav.txt`），保存至音频所在文件夹；跳过已有同名目标和无时间轴 TXT，保留原 TXT，并列出各文件的导出结果。时长无法读取、权限不足等会列为失败。
返回应用、切换曲目或打开字幕菜单时，会检查已关联字幕是否仍存在；扫描也会清理已删除的手动关联。权限不足且不能确认删除的文件会保留记录，避免误删关联。

### 新版功能

- 「设置」提供随系统、亮色、暗色主题，以及绿、蓝、紫强调色。
- 文件夹使用星形收藏，单首音频使用爱心收藏；音频库「收藏」内分为「文件夹」和「单曲」，已有收藏记录继续保留。
- 「排序」可选名称升序、名称降序、最新修改、最早修改；进入分组时按所选顺序创建播放队列。
- 「视图」可选列表、小网格、中网格、大网格；主题、排序、视图和收藏会保存。
- 「设置 → 悬浮字幕」首次启用时需在安卓系统中允许 ASSSMER 显示在其他应用上层，再返回应用。
- 悬浮字幕跟随播放器的当前曲目、字幕选择和同步偏移；可拖动位置，点 × 关闭。无时间轴的文稿无法自动同步显示。
- 播放服务结束后悬浮字幕也会关闭；再次需要时在设置中启用。
- 升级安装后重新扫描一次音频库，即可关联已有的双后缀字幕。

### 文件夹结构

```text
RJ10/
├── A/
│   ├── 1.MP3
│   ├── 1.TXT
│   ├── 2.MP3
│   └── 10.MP3
├── B/
│   └── 1.MP3
└── Bonus/A/
    └── 1.MP3
```

音频库分别显示 `RJ10/A`、`RJ10/B`、`RJ10/Bonus/A`。不同导入根目录使用独立标识。
`A` 内按 `1、2、10` 的自然数字顺序播放，默认只在同一分组内连续播放。

### TXT 自动转换

```text
【00:01.500 你好，欢迎收听。】
[00:05.200] 接下来请放松。
00:12.000 慢慢闭上眼睛。
```

TXT 内容为 SRT/VTT 格式时自动识别时间区间和字幕编号，正文仅显示对白；兼容缺少段落空行的编号字幕。已由旧版错误导出的字幕请重新选择原 TXT 再导出。
支持 `分:秒`、`时:分:秒`、小数毫秒（点或逗号）、中英文括号等常见时间格式。
一条开始时间对应一段文字，默认到下一条开始时间结束，末条到音频结束。
导入或重新扫描文件夹时，同目录同名的带时间 TXT 会自动转换为应用内部的 VTT 文件；原 TXT 保留，不需要逐个打开音频。
少数暂时无法读取时长的音频会显示提示，并在播放时重试转换。
播放页格式菜单中的「导出字幕…」可选择 VTT 或 LRC，保存选择器默认打开当前音频所在目录。系统文件提供方可能忽略默认目录提示。
VTT 保留每句开始和结束时间；LRC 使用毫秒时间标签，重叠字幕合并为同一行，并使用空时间标签保留字幕间隔。
普通无时间 TXT 显示为文稿，不能导出同步字幕。错误时间、倒序、超时等会显示解析提示。
播放页每句字幕只显示文字，不显示时间标签；同步高亮和点击跳转继续使用原时间轴。
支持 UTF-8、带 BOM 的 UTF-16，以及 GBK / GB18030 文本。

### 使用边界

- 常见音频容器交由 Media3 播放，具体编码兼容性取决于设备。不能播放时会显示提示。
- ASS/SSA 支持对白文字与时间，不复现完整特效、位置、字体样式。
- 增强 LRC 支持逐字时间高亮。字幕偏移是独立的播放显示设置，导出保留原时间。
- 不包含云端账号、在线内容库或无时间 TXT 的语音自动对齐。
- 系统对存储根目录、下载根目录及 Android/data 等位置有限制，建议导入 Documents 或 Music 中的作品子目录。
- 本地测试包使用开发签名；正式发布前需要确定包名、正式签名密钥和发布渠道。

## 开发

Android Studio 打开本目录。SDK 位置由 Android Studio 配置到不提交的 `local.properties`。
Java 使用 Android Studio 自带 JBR；Gradle Wrapper 固定 9.1.0，AGP 固定 9.0.1，Media3 固定 1.9.3。

```powershell
./gradlew.bat assembleDebug testDebugUnitTest
```

测试 APK 在 `app/build/outputs/apk/debug/app-debug.apk`。
字幕与自然排序的单元测试覆盖 TXT→VTT 回读、最后一句结束时间、错误时间、编码、LRC、SRT、VTT 重叠及 ASS。
运行 `python scripts/generate_test_fixtures.py` 可以生成测试素材。
模拟器集成测试需要先把 `test-assets/RJ10` 复制到模拟器 Documents 文件夹，并通过系统选择器导入，再运行：

```powershell
./gradlew.bat assembleDebugAndroidTest
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
# 请在应用中先导入测试目录，然后执行：
adb shell am instrument -w com.asmr.player.test/androidx.test.runner.AndroidJUnitRunner
```

集成测试验证真实目录授权与扫描、字幕关联、双后缀文件名、父目录定位、自动 VTT 文件、连续播放、倍速跳转、进度保存、设置保存及后台睡眠定时与悬浮字幕。
测试音频为生成的测试音调，不作为应用内容发布。
测试期间请不要同时运行 UI dump 或点击模拟器；Gradle 的 connectedDebugAndroidTest 默认会在结束后卸载应用，手动运行可保留授权数据。
